# zc

A lightweight network tool built with Zig.

## Installation

Requires [Zig](https://ziglang.org/) 0.15.0+ and [just](https://github.com/casey/just):

```bash
git clone https://github.com/ekil1100/zc
cd zc
just install
```

## Quick Start

```bash
# Start TUI
zc tui

# Start service
zc start

# Check status
zc status
```
