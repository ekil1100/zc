# zc

A lightweight network tool built with Zig.

## Installation

Requires [Zig](https://ziglang.org/) 0.15.0+ and [just](https://github.com/casey/just):

```bash
git clone https://github.com/ekil1100/zc
cd zc
just install
```

## Quick Start

```bash
# Build and install
just install

# Start service
zc start

# Start service on an explicit local-dev port
zc start --port 7901

# Check status
zc status
```
