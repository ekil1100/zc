## v1.0 definition

zc v1.0 is a CLI-first proxy runtime with:

- default mixed inbound;
- daemon lifecycle commands with per-user, owner-only runtime artifacts;
- explicit local-dev port override;
- DIRECT、REJECT、四种 Shadowsocks AEAD cipher（plain/simple-obfs HTTP TCP，以及 mixed SOCKS5 UDP ASSOCIATE 上的 classic AEAD UDP）与 Trojan TCP/TLS 出站；
- simple-obfs HTTP 与 Shadowsocks AEAD UDP 均已关闭独立 wire、真实 socket、资源、生命周期和固定版本互操作门禁；
- 未经 wire、互操作、资源和生命周期验证的协议在 bind/dial 前 fail closed；
- core rule matching;
- rule-provider expansion;
- 有固定连接数、framing、大小与期限上界的 loopback minimal API;
- install/verify/upgrade/rollback validation scripts.

v1.0 is **not** a full mihomo/clash replacement.

### P0-2: Unified v1 capability gate — verified Shadowsocks expansion done

v1.0 以 `direct`、`reject`、`aes-128-gcm` / `aes-256-gcm` / `chacha20-poly1305` / `chacha20-ietf-poly1305` Shadowsocks TCP（plain 或精确 simple-obfs HTTP），以及 Trojan TCP/TLS 为已发布基线。Shadowsocks 扩展按以下严格顺序推进：

1. ~~实现并验证内置 simple-obfs HTTP 流式 transport~~（done）；
2. ~~仅为 `plugin: obfs|obfs-local` + 显式 `mode: http`、合法 host 开放 capability~~（done）；
3. ~~实现经典 Shadowsocks AEAD UDP 与 SOCKS5 UDP ASSOCIATE~~（done）。

2026-08-06 的 simple-obfs capability-enable gate 使用真实 ReleaseSafe zc、mixed HTTP/SOCKS5、test-only 独立 obfs oracle、固定 `shadowsocks-rust v1.24.0` 与本地 origin 完成 round-trip。oracle 独立验证 GET/Host/Upgrade/Connection/Key/Content-Length，并覆盖分片 101 header 与 same-write tail；`tls`、未知 plugin/mode、缺 options/host、CRLF 和当时尚未开放的 UDP 均在 bind/dial 前失败且 oracle counter 不增长。这是保留日期语义的历史记录。

2026-08-08 的 UDP capability-enable gate 进一步使用独立 Node literal-vector generator、test-only Zig UDP oracle、真实 ReleaseSafe zc mixed SOCKS5 UDP ASSOCIATE、dual-stack UDP echo 和固定 `shadowsocks-rust v1.24.0 -U`。三种 wire 算法及 `chacha20-poly1305` alias 均完成 IPv4/domain/IPv6 round-trip；门禁还覆盖 bad tag、截短 salt/tag、RSV/FRAG/ATYP/长度、65507/max+1、client IP/source port pin、control close、64+1 capacity、`udp:false` REP 07、DIRECT/非 UDP leaf 无 fallback，以及 simple-obfs TCP-only bypass。Darwin arm64 本地验证中，Debug/ReleaseFast 各 1059/1059 tests、ReleaseSafe `e2e` 与 ReleaseFast `e2e-release` 各 15/15 steps 和 46/46 oracle tests 均通过，x86_64/aarch64 Linux musl 与 x86_64 macOS ReleaseFast build 通过；Linux install prefix 仅含 static `zc`。`mode: tls`、通用外部插件、AEAD-2022、standalone `socks-port` UDP、fragmentation、Trojan/AnyTLS UDP 仍明确拒绝。研究与验收依据见 [`../research/shadowsocks-simple-obfs-udp.md`](../research/shadowsocks-simple-obfs-udp.md)。

HTTP、SOCKS5、VMess、VLESS、AnyTLS outbound 和其他未接线 transport 仍必须由 validator、doctor 与 runtime 在 bind/dial 前一致 hard reject。保留协议源码不代表支持。

### P0-6: Reliable proxy selection and local config import — in progress

当前代理选择可能让持久 metadata 与 daemon runtime 状态分裂。legacy `meta.json` 现以 owner-only `0600` 临时文件完成 sync 后原子替换并同步父目录，读者只会观察完整旧值或新值。v1.0 计划要求：

- revisioned managed-config identity；
- 使用单调 generation 的 durable desired selection；
- daemon 接收流量前先完成启动对账；
- 明确区分 desired/runtime 与 selected/resolved；
- 提供 CLI-only `zc config load <path>`，导入经过验证的本地配置 bundle 并设为 active；
- 只有 TCP、UDP 和多路复用逻辑 flow 都具备安全追踪与取消后，才开放可选连接关闭；
- 通过 crash recovery 与 ReleaseFast 性能门禁。

`zc config load <path>` 已把本地 YAML 与 root-contained assets 导入 immutable revision、刷新 mirror 并设为 active。`list/download/update/use/delete/dump/override` 也已切换到 catalog v2 authority；`meta.json` 与 `configs/` 只保留为派生兼容镜像，subscription update 以读取到的 exact head revision 做 CAS。`proxy select` 已改为 durable-first generation commit，daemon 通过 immutable revision exact loader 取得配置与 identity，在开放 listener 前恢复同一 revision 的 authority desired state；override/unmanaged 运行不冒充 managed identity。后台 `start` 只在 parent 完成 provider/override preparation、所有 listener 就绪且 descriptor 原子发布后成功；child 仅加载 owner-only、HMAC 绑定的 immutable runtime snapshot。`restart` 按 PID/nonce 绑定旧实例，在 stop 前完成完整 preparation，post-stop 启动失败时恢复原 snapshot；reload 保留 canonical source 与 CLI port override。CLI 仅通过 PID/revision 匹配的 live runtime descriptor 使用精确 loopback controller endpoint；descriptor 不可信时只持久化、不猜测配置端点。端口冲突时启动失败，不漂移或静默禁用控制面。当前 CLI 契约以 [`docs/cli/spec.md`](../cli/spec.md) 为准；P0-6 仍需完成最终 fault/crash 与 ReleaseFast 门禁。
