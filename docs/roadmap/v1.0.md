# zc v1.0 完成记录

> v1.0 实现路线图已关闭。本文保留发布范围与验收入口，不再作为进行中的任务清单。

## 状态

v1.0 计划内工作已经完成，`v1.0.0` 是正式发布基线。后续功能与改进不再追加到本路线图，应作为新版本工作独立规划。

GitHub Release、standalone installer 与下游包管理渠道均以最新正式 tag 的产物为准。

## v1.0 范围

zc v1.0 是一个 CLI-first 代理运行时，提供：

- 默认 mixed inbound；
- owner-only、instance-bound 的 daemon 生命周期与运行时状态；
- `start`、`stop`、`restart`、`reload`、`status`、`log`、`doctor` 等稳定 CLI；
- 统一的文本/JSON 输出与退出码契约；
- revisioned managed config、immutable bundle、本地 `zc config load <path>` 与 durable proxy selection；
- DIRECT、REJECT、四种 Shadowsocks AEAD 配置名对应的 classic TCP/UDP 能力，以及 Trojan TCP/TLS；
- simple-obfs HTTP TCP 与 mixed SOCKS5 UDP ASSOCIATE；
- 核心规则匹配与 rule-provider 展开；
- 有固定资源上界的 loopback minimal API；
- standalone installer、静态 Linux 产物、checksum、Homebrew Tap 与真实网络 E2E 发布链路。

v1.0 不承诺完整 mihomo/clash 替代能力。HTTP、SOCKS5、VMess、VLESS、AnyTLS outbound，完整 mihomo DNS、TUN/redir/tproxy、完整 REST API v1、WebSocket 事件流和 TUI 均不属于本版本范围；未经验证的能力继续在准入阶段 fail closed。

## 完成的发布门禁

v1.0 的实现与发布链路覆盖以下门禁：

- Zig 0.16.0 Debug 与 ReleaseFast 构建测试；
- Linux amd64/arm64 musl 与 macOS amd64/arm64 构建；
- config migrator 与 install regression；
- standalone one-line installer 与 SHA-256 校验；
- 真实 mixed HTTP/SOCKS5、minimal API、Shadowsocks、Trojan 与 daemon lifecycle E2E；
- isolated HOME / XDG_RUNTIME_DIR 下的 daemon smoke；
- revisioned config、durable selection、fault/crash、runtime identity 与安全边界回归。

发布前仍应执行常规版本验证；这些命令是发布操作的一部分，不再代表未完成的 roadmap 工作：

```bash
git status --short --branch
env ZIG_GLOBAL_CACHE_DIR=/tmp/zig-cache zig build test --summary all
env ZIG_GLOBAL_CACHE_DIR=/tmp/zig-cache zig build -Doptimize=ReleaseFast --summary all
bash tools/config-migrator/run-all.sh
bash scripts/install/run-all-regression.sh
bash scripts/install/test-oneline-installer.sh
bash scripts/run-full-validation.sh
zig build e2e --summary all
./zig-out/bin/zc start --port 29001 -c testdata/config/minimal.yaml --json
./zig-out/bin/zc status --json
./zig-out/bin/zc stop --json
```

端口 `7899` 继续保留给生产环境，本地 smoke 使用显式非生产端口。
